## User Goal
Пользователь удаляет существующий объект.
## Actor
Пользователь (User)
## Trigger
Пользователь инициирует удаление объекта сущности через интерфейс системы.
## Preconditions
- PRE-1 Пользователь аутентифицирован.
- PRE-2 Пользователь находится в интерфейсе управления объектами сущности.
## Postconditions
- POST-1 Success Guarantee: Объект сущности удален из системы.
- POST-2 Minimal Guarantee: В случае ошибки состояние системы не изменяется.
## Main Scenario
1. Пользователь выбирает операцию удаления объекта.
2. Система запрашивает подтверждение удаления.
3. Пользователь подтверждает действие.
4. Система проверяет возможность удаления объекта.
5. Система удаляет объект из базы данных.
## Alternative Scenarios and Extensions
- 2a. Отмена удаления
1. Пользователь отменяет удаление объекта.
2. Система прекращает выполнение сценария.
3. Объект не удаляется.
- 4a. Нарушение бизнес-правил (есть связанные объекты)
1. Система обнаруживает нарушение бизнес-правил.
2. Система отображает сообщение об ошибке (информирует о невозможности удаления из-за связанных объектов).
3. Сценарий завершается.
## Exceptions
E1 Системная ошибка (на шаге 5)
1. Происходит технический сбой при удалении объекта из базы данных.
2. Система фиксирует ошибку.
3. Система отображает сообщение о невозможности завершить операцию.
4. Сценарий завершается.
## Business Rules
BR-0 Пользователь может управлять только своими объектами.  
Бизнес-правила для объектов конкретных сущностей определяются в соответствующих сценариях.
## Notes
Данный сценарий является шаблоном для операций удаления объектов системы (траектория, навык, действие).
