# UC-34 View Action
## Related User Stories
- US06 – Просмотр действий навыка
## Template
Based on the [View Entity Template](./templates/View-Entity-Template.md)
## Extensions to Main Scenario
- Пользователь может найти действие по названию.
- Пользователь может фильтровать список действий по траектории, навыку, типу действия и статусу.
- Пользователь может выбрать действие из списка для перехода к просмотру подробной информации о действии.
## Linked Entities
- Skill
- Action type
- Trajectory (indirectly via Skill)
