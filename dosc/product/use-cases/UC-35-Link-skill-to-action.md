## User Goal
Пользователь связывает существующий навык с действием.
## Actor
Пользователь (User)
## Trigger
Пользователь инициирует добавление навыка к действию через интерфейс системы.
## Preconditions
- PRE-1 Пользователь аутентифицирован.
- PRE-2 Пользователь находится в интерфейсе управления действиями.
- PRE-3 В системе существует хотя бы один навык, доступный для привязки к действию.
## Postconditions
- POST-1 Success Guarantee: Навык привязан к действию.
- POST-2 Minimal Guarantee: В случае ошибки состояние системы не изменяется.
## Main Scenario
1. Пользователь выбирает операцию добавления навыка к действию.
2. Система отображает список траекторий пользователя.
3. Пользователь выбирает траекторию.
4. Система отображает список навыков выбранной траектории пользователя.
5. Пользователь выбирает навык.
6. Пользователь подтверждает сохранение.
7. Система валидирует данные.
8. Система сохраняет связь между действием и навыком.
9. Система отображает добавленный навык в списке связанных с действием навыков.
## Alternative Scenarios and Extensions
- 3a. Отмена добавления навыка (на шагах 3-4)
1. Пользователь отменяет добавление навыка до подтверждения сохранения.
2. Система прекращает выполнение сценария.
3. Навык не добавляется.
- 5a. Нарушение бизнес-правил
1. Система обнаруживает нарушение бизнес-правил (например, навык уже связан с данным действием).
2. Система отображает сообщение об ошибке (например, навык уже добавлен).
3. Возврат к шагу 5.
## Exceptions
E1 Системная ошибка (на шаге 8)
1. Происходит технический сбой при сохранении данных.
2. Система фиксирует ошибку.
3. Система отображает сообщение о невозможности завершить операцию.
4. Сценарий завершается.
## Linked Entities
- Skill
- Trajectory (indirectly via Skill)
## Business Rules
- BR-0 Пользователь может управлять только своими объектами.  
- BR-1 Навык не может быть добавлен к действию более одного раза.
- BR-2 Действие может быть связано с несколькими навыками.
## Notes
Данный сценарий реализует управление связью many-to-many между сущностями навык и действие в контексте действия.
