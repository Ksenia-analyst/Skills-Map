# Skills Map
Цифровой инструмент для управления персонализированной траекторией развития навыков в любой предметной области.

Репозиторий содержит документацию MVP версии приложения.

## MVP Skills Map
Персональный веб-прототип, реализующий основную концепцию продукта. Предназначен для хранения и систематизации информации, накопленной в ходе самостоятельного обучения бизнес- и системному анализу, а также для отработки профессиональных навыков.  

Функциональность сознательно ограничена рамками MVP. Проект не предусматривает коммерциализацию, масштабирование и поддержку большого количества пользователей.
